# Eshita Lopes — Portfolio

A responsive static portfolio with a custom dark "Signal / Systems" visual identity.

## Files
- `index.html` — portfolio site
- `Eshita-Lopes-Resume.pdf` — downloadable resume

## Run locally
Open `index.html` in a browser. No build step is required.

## Deploy
- Vercel: import/upload this folder as a static project.
- Netlify: drag and drop this folder into Netlify Drop.
- GitHub Pages: upload the files to a repository and enable Pages.

## Updated interactions
- "Let's connect" opens an email draft addressed to Eshita with a suggested subject and starter message.
- Resume links download `Eshita-Lopes-Resume.pdf`.
- GitHub links open `https://github.com/eshitalopes10`.
- Scroll reveal, animated identity ticker, ambient glow, gradient motion, and hover sheen are included. Reduced-motion preferences are respected.
